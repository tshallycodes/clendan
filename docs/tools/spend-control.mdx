# Spend Control

Spend Control merges accounts payable and expense enforcement into one outgoing spend layer. Bills from connected accounting sources are processed alongside employee expenses, with a unified policy engine enforcing per-transaction limits, category caps, and pre-approval routing before any payment is released.
