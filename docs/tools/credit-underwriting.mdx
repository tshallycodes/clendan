# Credit Underwriting

The Credit Underwriting tool evaluates applicants against configurable credit score, DTI, LTV, and employment criteria. Decisions above the auto-approve threshold are issued instantly; borderline applications are routed for human review with a full reasoning trace and automatic adverse action notice generation where required.
